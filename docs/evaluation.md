窗口左闭右开，起点一次性预测，期间不更新。历史先按时间截取，再归一为最新用户/父商品评分。

目标是发现历史未评价父商品：窗口内首次新父商品评价定义答案，评分 ≥ 4 为正向；窗口内后续重复不修改首次标签。历史已见商品的重复事件另计，不当新目标。

候选白名单仅由训练期选择，两个阶段保持同一 5,000 商品。各模型过滤全部已见（含低分），相同分数按字符串 ID 升序；负分、零分仍参与排序。MF 未拟合用户及 BPR 无有效三元组用户统一零分；无历史热门兜底单独作为策略报告。

## 训练与结果

固定 factors=16、SGD lr=0.5、batch=256、L2=0.001、seed=42；最多 20 轮，每 5 轮按验证 Recall 选择，同分取较早。所有模型选择先保存，再从头拟合训练+验证历史和计算测试。MF 选择 15 轮，BPR 选择 5 轮。没有测试后搜索配置或扩轮数。

| 策略 | 测试 Recall@10 | 测试 NDCG@10 |
| --- | ---: | ---: |
| 热门 | 0.0079104120 | 0.0045446280 |
| MF | 0.0008235773 | 0.0005388056 |
| BPR | 0.0002489885 | 0.0001175379 |
| BPR + 仅无历史用户热门兜底 | 0.0062153750 | 0.0036411922 |

混合策略对 5,104 位窗口用户走热门、1,970 位走 BPR。它改变路由，没有更新模型，纯热门总体仍更高。候选限量与大量冷用户是显著限制，不能称高质量全类目个性化。

本机 Apple M5 / 16GB、CPU 单线程 float32 确定性运行：处理 12.587 秒，峰值 RSS 约 319MiB；真实 MF/BPR 编排 102.470 秒，峰值约 567MiB。限于此次机器和规模，不是吞吐或跨后端性能结论。

已独立复算四指标和验证选轮，四份检查点重载重现逐用户列表；本地 HTTP 与 Python 结果一致。服务混合策略对全部 7,074 测试用户重放，与冻结分支列表一致。数据、权重与逐用户日志仅保留本地，不随仓库再分发。

### 审计字段修正

首次真实实验的选轮器仅统计有新商品目标的用户：6886 总人数、1693 无正例；完整窗口为 6888 / 1695，两者有效用户均 5193。差异来自两位只重复评价旧商品的用户，不影响四项均值、选轮或权重。当前 runner 补全窗口人数并记录 `cohort` 三计数；历史实验报告保留原样，没有因此重训。

## 结论边界

当前商品模型为单种子固定有限配置；热门阶段已查看测试，不称新盲测或各模型最优。历史评价不是曝光/购买日志，也不是购买前对话。当前尚未实现长期偏好记忆或开展记忆增益实验，不能将已有结果归因于记忆。
