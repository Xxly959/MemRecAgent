## 行为与接口

新增product_attributes.py：ProductAttributeValue保存属性、类型化值、单位、来源和available_at；RequestConstraint保存比较及user/session/beneficiary/request_id、证据引用和时间。支持price_cny/CNY、weight_g/g、battery_life_hours/h、screen_inches/inch、storage_gb/GB的正有限数，screen_type/type字符串，eye_care/bool严格布尔。数值支持<=、>=、==；枚举/布尔仅==。拒绝不匹配单位、NaN、布尔冒充数值和未知属性，禁止自动猜测或换算。

ProductEntityFact新增默认空attributes元组，每属性唯一。每项事实独立有来源/可用时间，只有available_at严格早于查询才可用；不存在或未来属性按unknown处理。对象不可变，不把缺失值当0，不根据品牌或商品标题补规格。

ranker.recommend新增constraints=()及request_id=None。非空约束必须绑定明确请求ID，全部约束的用户/会话/受益人/请求及证据时间须匹配；同属性同方向出现多条限制被拒，要求宿主先解决新旧覆盖。不能将<=2500与本次<=4000默默取交集。该接口接收的是已解析的本次有效限制，当前没有自动解析跨轮预算覆盖。

先对完整未见候选计算旧基础分与归一化，再按品牌及属性过滤，最后TopK。预算过滤不改变基础特征的归一化池；四组都使用相同当前约束。缺失属性记attribute_unknown，已知不满足记attribute_constraint；每商品只记第一个失败原因，过滤原因数不能当所有谓词违例次数。没有合格商品就返回空列表，不自动放宽预算。

偏好B的加分不能使超预算B入选；给他人推荐只用对方明确绑定的限制及原公共基线。关闭长期记忆仍保持本次约束；本增量不读取或修改长期属性。

## 实际入口

Python只读工具的可信request可带constraints/request_id，facts各商品可带attributes。LLM工具参数仍为空对象，不能改用户、预算或路径；原字节摘要发布凭据覆盖新增字段，预算或目录属性变化后旧凭据失效。

memory_products.decode_product_entity_fact供只读工具、持续对话桥接和离线四组共用，避免一条入口接受、一条拒绝相同属性目录。无属性旧目录与默认旧行为兼容；新增属性文件不能被旧版本解析器保证兼容。

持续对话桥接现在可以加载含属性的目录；自然语言process_user还未生成RequestConstraint，不能把“加载成功”说成已经理解用户口头预算。实际Pi本轮证据使用可信宿主绑定的结构化预算。

请求片段示意：

```json
{
  "request_id": "request-1",
  "constraints": [{
    "user_id": "synthetic-user", "session_id": "S2", "beneficiary_id": "self",
    "request_id": "request-1", "attribute": "price_cny", "operator": "<=",
    "value": 3000, "unit": "CNY", "evidence_ref": "S2:T1",
    "available_at": "2026-10-23T00:00:00+00:00"
  }]
}
```

这只是增加到原完整绑定请求的字段，不是完整CLI输入；查询时间必须晚于证据时间。
