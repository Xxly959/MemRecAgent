# Phase2本地推荐API契约

> 公开整理版：保留工程方法、结果和失败；本机路径已泛化，内部记录及原始产物留在本地。

2026-10-20。当前为实现前冻结的接口契约，验证结果以PHASE2-PROGRESS为准。

## 冻结推理包

从固定处理目录和已验证模型运行生成新目录，包含bundle.json、service.json、mf.pt、bpr.pt。service.json仅含候选、拟合截止前全部已见、对应热门计数和候选展示快照；不包含测试标签、未来事件或评论正文。二进制仅张量与基本类型。

bundle记录各文件SHA256，ID由完整清单内容确定。加载时核验清单ID、文件哈希、模型词表与候选一致；只在进程启动加载，不在请求中读取训练数据或更新模型。不覆盖已有包，后续源文件改变不改变已冻结包。

## 请求与响应

- GET /health：ready、bundle_id、历史截止、候选数量与可用策略，不暴露原始用户列表。
- POST /recommendations：必需user_id、bundle_id、strategy；k默认10，严格整数1–50。拒绝额外字段及任意as_of，版本不符409，非法参数422。
- strategy为popularity、mf、bpr或bpr_cold_popularity，客户端显式选择，不按已查看测试选择默认优胜模型。
- bpr_cold_popularity仅在用户完全没有历史时走热门；只有白名单外历史、无正向或列表为空不自动触发。用户有历史但无候选内模型向量时明确记录，不伪造个性化。
- 响应包含版本、历史截止、请求/实际策略、已见过滤计数、候选数、返回数；每项有父商品ID、可取得标题/类别、真实原始分数及元数据来源定位。缺元数据返回未知，不删除该候选。
- 候选不足返回短列表，无候选返回空列表及原因；列表唯一且不含已见。没有实时价格、库存、购买概率或LLM生成事实。

元数据标记为展示快照，其available_at未知；不能把快照时间说成历史商品事实生效时间。模型原始分数不与热门计数混成同一概率尺度。

## 本地运行边界与依赖

先验证Python调用，再用FastAPI/Pydantic封装及Uvicorn绑定127.0.0.1；不提供公开部署、认证、数据库或前端。FastAPI/Pydantic/Uvicorn属于api运行extra；HTTPX2仅用于dev中的HTTP契约测试。安装保持ml与api两个extra，更新uv.lock。

实测Starlette1.9.0的TestClient优先使用httpx2，仅有httpx时发出弃用警告；已核对本地源码和官方https://starlette.dev/testclient/，采用httpx2替换，不过滤警告或保留无用途的两套客户端。FastAPI部分教程仍写httpx，以实际兼容测试和当前上游说明为准。

需验证版本不匹配、非法参数、冷用户、缺元数据、空/短列表、已见过滤、参数不变、冻结包独立于未来源文件、损坏包拒绝及真实本地HTTP请求。离线重放API命名策略的成绩单独报告，不混入纯MF/BPR。
