## 用户可用行为

可信本机`manage_memories.py`新增inspect/forget/forget-feedback/recover，不调用模型。
inspect显式显示品牌/属性历史及当前持久反馈；原文只在用户主动私有查看时输出。
forget brand同时删同类别品牌偏好全部修订与同品牌反馈；product只删精确商品反馈，不扩大到品牌；
attribute删除该属性全部比较方向、硬软历史。forget-feedback仅删反馈，保留同品牌偏好。
旧delete命令保持原先仅删品牌偏好的兼容语义。列表显示的反馈摘要不包含原对话或展示令牌。

两个底层文件先在私有stage生成新快照并严格解码；源文件摘要从首读前固定、发布意图前再次核验。
只含owner/随机stage目录名/前后摘要的意图先fsync发布，再替换两文件。
意图存在时，品牌/属性store、反馈store的公开读写和推荐均拒绝，当前会话fresh清派生引用/旧回执。
显式recover检查全部当前before/after摘要和待发布after文件，再完成剩余发布；未知漂移/坏文件保持阻读。
成功后清stage/标记，保留既有删除水位/摘要收据防旧证据/展示重放。

这是可恢复的单进程串行发布，并非跨进程事务；不能同时运行多个写入者。
意图发布前进程硬退出，尚未开始删除且可能残留私有预备目录；正常异常清理该目录。
意图发布后中断须recover，不能手工删marker绕过保护。相关文件/目录fsync不构成所有设备断电保证。
不删除训练模型/行为数据，不擦除外部副本/日志或承诺物理介质清零；用户ID不是身份认证。
