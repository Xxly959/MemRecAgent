## 已实现与边界

memory_extraction.py提供严格候选JSON契约和用户原话码点区间校验；memory_proposals.py区分态度主体和推荐对象，生成本人长期修订提案或当前会话偏好；deepseek_client.py提供固定官方HTTPS端点、关闭思考的JSON请求；memory_extraction_evaluation.py及CLI执行冻结合成集和记账。

本轮仅提案，不自动写入真实长期记录。模型不指定用户ID、记忆ID、修订引用或时间；程序从可信用户/会话/轮次及当前链头推导。模型合法JSON仍可能语义错误，程序校验不证明提取准确。

长期只保存本人。他人即使说“一直喜欢”，也仅转换成当前会话偏好；主体未知且与本人明确对立时澄清；推荐对象已知，不意味着每条喜好的主语也已知。本次明确查看临时覆盖旧排除；明确长期取消以neutral提案修订，不变成喜欢。
