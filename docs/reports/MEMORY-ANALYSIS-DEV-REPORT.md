## 失败与归因

direct有2次quote_ambiguous、5次interaction_unrelated。analyst有1次quote_ambiguous、5次interaction_unrelated、1次interaction_intent_assertion、1次interaction_latest。严格步骤差异共有5处：analyst改善D01/T2，但倒退D04/T2和D12/T4–T6。D12/T4提取失败导致后续实际记忆缺失，T5–T6虽调用成功仍状态/激活错误；错误传播没有被gold修复掩盖。

两组显式他人归属/当前范围/引用污染指标都为0，但dev仅2个标注他人归属机会；wrong_scope只覆盖显式current_only，不能泛化成无任何人物/范围风险。

两组各1条错误写入来自D07/T2：“我现在反而更喜欢三星手机了。”gold要求先问长期还是本次；仅看截至该轮的信息，也可合理解释为稳定改口。不能利用未实际发送的T3来论证T2只能如此解释。保留原gold和计分，单列政策标注争议，待独立复核；不为追分改题或修提示。

当前两组同时改变调用数、最终角色提示和草案选取的相关记忆view，是完整策略对比，不能单独证明“二次复核”因果。固定先后顺序也混入缓存预热/供应商时间效应。应补第二次不看草案、同view等控制；后续测试集仍封存，不能用来反复调提示。
