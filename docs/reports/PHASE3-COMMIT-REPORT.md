## 本次完成

- 新增`memory_commit.py`：`MemoryCommitSession`绑定存储根、用户、会话；`prepare`生成只读预览与宿主持有的随机票据，`commit`根据票据提交，模型不能传入任意路径、归属或待写记录。
- 动作为`apply/current/clarify/noop`。明确本人长期表达可以由宿主显式提交；本次/他人表达不持久化；未知主体无明确对立时不猜本人、不追问；本人范围明确标为unclear时询问。neutral无旧链不建立长期空记录。
- `confirm`接受真实新用户轮次与可信调用方的结构化主体/范围选择；他人只能current且有新回复中的人物锚点。回复必须晚于待确认预览、早于当前读取时刻、角色为user且ID未使用。原表达与回复共同保留证据；确认生成新票据，不直接写入。
- 喜好主体与推荐受益人分开；确认态度是谁的，不改原本明确的推荐对象。单次确认只处理一个一致目标；多人物、实体、矛盾态度及未解决品牌/关系需要重述。仅查看品牌不能变成长期喜欢。
- 新增`memory_store.snapshot_token/add_many`。状态摘要包含删除水位，状态变化使旧票据拒绝。批量先校验归属、旧链、时间、删除水位和全部记录，再一次原子发布；末条失败不会留下前条。单条add复用批量路径，旧接口测试保持。
- 重复提交已成功票据只在原记录仍完整存在时返回already_applied；删除后拒绝，不恢复旧内容。新有效预览替换旧票据，cancel可取消当前票据。票据只在内存，重启需重新提案。
