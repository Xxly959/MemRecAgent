## 指标和分母

- 按本轮实际新增记录计算写入精确/召回；重复记录不重复记功。极性准确率仅以已预测且实体应写入的记录为条件，不能替代整体正确率。
- 错误归属、当前范围误长期化、引用污染：当实体只属于被禁止来源时，即使模型连极性也改错，仍统计污染。混合本人/他人同实体不同态度时区分事实，避免把合法本人写入记为污染。
- 修订需要实际supersedes指向此前存在的同实体记录。heads/本人激活/他人上下文/动作各自精确检查；完整故事需全部计划步成功。
- 无实际写入时precision=null，无应写入时recall=null。零错误提供单侧95%二项上界，但记录可能相关，只作描述性数值，不能据此宣称真实人群安全概率。
- 供应商/冻结/预算失败停止新请求，剩余计划轮not_run仍留总分母；处理/解码失败记录后可继续故事。未实际问问题的条件回复unasked_reply，不发送模型。
- 草案和最终角色失败时仍保留所有实际调用记录；请求尝试不等同于已知物理HTTP成功。reported token总和与缺失字段数并列，未知用量不当零消费。失败尝试也记录wall_seconds；该值包含包装器与验证开销，不冒充纯模型计算时间。
