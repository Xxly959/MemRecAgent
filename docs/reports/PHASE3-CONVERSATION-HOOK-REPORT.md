## 本次实现与接口

新增`src/memrecagent/memory_interaction.py`：`ConversationMemorySession`接收实际用户和助手轮次，依次提供`observe_assistant`、`prepare_user`、`commit`、`cancel`。预览返回意图、原文话题、会话线索、相关本人记忆、底层提交预览及回答动作。它供对话Agent调用，不生成手机事实、商品列表或排名。

模型每个用户轮次只分析一次。原文引用经Task1严格解码后，复用原提案/人物/票据/原子写入。初次分析只接收实际历史，不倾倒所有本人偏好；解析出咨询/比较/推荐后按动作读取相关背景。跨会话含糊指代仍可能需重述或澄清。模型失败不自动重试、不写盘，保留实际发生历史并使旧交互提交入口失效。

- 咨询/比较：返回相关背景，旧排除不变成“拒绝讨论该品牌”；明确为他人咨询不套用本人喜好。
- 弱线索：预览不发布，只有commit接受后保留在当前工作区；不写长期，不因单品体验直接改变品牌态度。
- 稳定本人表达：进入可审查的长期提案；提交才写盘。仅本次要求不改长期；他人稳定偏好复用既有会话银行，不写盘。
- 确认：仅当前待办、实际输出且紧邻回复的问题可绑定；问题内容、角色、ID和时间都核验。单目标范围问的“后者”可选择长期；含糊“嗯”、多目标/普通多问题、旧问题不据此写入。
- 溯源：`MemoryCommitSession.confirm`新增可选`question`参数；缺省保持旧契约。确认后的冻结提案保留原用户断言、实际回复及标注为“assistant语境，非用户态度”的问题，不把助手话变成用户证据。
- 删除水位：线索在预览及接受前逐条核验本人/未知主体原始来源，旧新混合不按最大时间放行；发现已删来源明确报deleted_evidence并清空工作前缀。他人独立表达不当成本人来源删除。若调用方重新提供删除前原话，首轮分析仍可能看到它，宿主在解析到实体/来源后拒绝保留；不宣称实现外部调用方原文全生命周期删除。
- 删除/外部纠正：存储摘要变化使整个工作区stale并清空原文、线索、人物和他人临时偏好；调用方以新前缀重试。此取舍避免关键词过滤遗漏混合来源，不能称无损会话恢复。存储root变化拒绝binding，不静默切换归属。
- 反馈：当前只返回`feedback_target_required`；可信卡片绑定、持久屏蔽/撤销和展示端仍是下一独立Phase3增量。

## 一个完整例子

| 实际用户表达/语境 | 程序处理 | 长期状态 |
| --- | --- | --- |
| 今天下雨了 | continue，不激活偏好 | 空 |
| 你怎么看三星？ | answer，提问不当喜欢 | 空 |
| 助手正常回答后：“三星系统我用着顺手” | 待核线索，commit后仅工作区 | 空 |
| 我一直更喜欢三星手机 | 明确稳定本人偏好，预览后commit | 三星prefer |
| 晚上吃什么 | continue，不激活手机偏好 | 不变 |
| 给我推荐手机 | recommend，返回实际决策激活的三星记忆 | 不变 |
| 这次只看小米手机 | 本次请求优先 | 三星仍prefer |
| 我现在取消对三星的偏好 | neutral修订保留旧证据链 | 三星neutral |

另测“我喜欢三星”范围未明→实际问“本次还是长期？”→用户“后者”。保存问题作为assistant语境，原断言和回复仍为user证据；预览阶段文件不变。未来真实模型若把咨询误判成喜欢，结构和引用合法本身无法证明语义正确，因此新模型验收必须单独做。
