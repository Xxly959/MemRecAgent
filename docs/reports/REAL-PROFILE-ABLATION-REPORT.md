## 冻结方案

- 活跃16个：BPR active/known、MF known、seen存在且有未见候选的交集，固定hash排序，保留原ID。
- 冷控制4个：确保标识不在任何模型词表/seen，不借用任何已拟合向量。
- 每人目标：从完整未见词表固定hash选1项，不看分数、输出或未来标签。
- 条件：独立目录中的prefer/exclude结构化反事实记录，证据明确不是该用户言语或已观察喜好。
- 实体：原counts的精确catalog-item ID及bundle来源；不造品牌。K10、原minmax/.75默认，四组共享事实/seen/请求。
- 私有计划含真实owner仅留本机忽略目录；trace/摘要用hash，不发给供应商。
- 排名前冻结40案例/目标/源码及原包；不因结果没改榜换人或换目标。无ground truth效用标签。
