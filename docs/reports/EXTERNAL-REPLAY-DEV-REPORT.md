## 实际执行

每故事从空库开始，跨session重建实际ConversationProductSession。
模型仅收实际用户话语和无标签目录，走正式解码、人物/原文/提交守卫。
评分端不回填预算、人物或状态。条件回复仅实际上一轮先问才发送。
未提问、处理失败、预算中止和未执行都留在90步/15任务计划分母。

首调前固定analyst先、direct后，各最多180/90调用，总270，无自动重试。
双阶段每轮需预留完整两次预算；供应商/宿主错误停止后续运行。
生产源码、依赖锁、派生数据和比较脚本封存，调用前后验摘要；显式合成产物记录实际
请求/响应/用量/耗时，不写凭证或请求头。
