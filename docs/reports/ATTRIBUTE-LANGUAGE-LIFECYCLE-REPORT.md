## 实际接口

schema4严格扩展v2/v3，新增attribute_changes列表；旧协议不允许混入新字段。模型提供带最新用户原文Quote的主体、类别、属性、方向、值、单位、硬软、生效标志及范围，不提供身份ID、时间、记录ID或修订父节点。新增/修订数值须在引用中找到，撤销用active=false/value=null，由宿主读取当前头保留旧值。纯dataclass不构成信任边界，公开宿主入口也重新编译原文与数值。

本人长期属性与品牌通过MemoryCommitSession同一票据、同一次add_many发布；存储失败不会先写一半，也不会先发布会话属性。重复提交幂等，删除水位拒绝旧证据。主体/范围不清则整轮澄清，要求包含具体条件、主体和范围的完整重述；当前不以旧品牌短答协议猜测属性，取消不提交。他人稳定属性仅在本用户本会话按精确人物来源保留，后续推荐可用，新会话不继承，不进本人磁盘。软属性可提取/保存，仍未接评分。

当前条件与长期记录分开：同方向本次要求覆盖长期条件；schema4的start/update可以明确remove_attributes，本次解除长期限制，结束/换人物/新会话后解除失效。没有提预算不等于取消旧预算。本轮明确属性在关闭长期更新或个性化读档时仍可用于当前推荐，不能借此开启未来保存或跨会话使用；该权限边界是在首测后发现并补回归修复的。
