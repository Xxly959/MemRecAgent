## 技术原理与验证例子

实际“我一直喜欢三星”即使草案误判unrelated，也继续运行独立角色。固定最终候选为本人prefer时，只有最终候选产生提案，两个调用期间及prepare返回时磁盘均未写入；commit后才有一条本人记录。反向控制中草案带强态度/线索、最终为无操作，commit后均不发布草案。

已有本人排除小米、苹果时，“这次给我推荐小米，旧排除不要改”向分析角色只传相关小米记录；最终宿主临时解除小米排除，苹果排除仍保留，磁盘两条旧记录均不改。给母亲推荐不传本人偏好，母亲态度只入会话。固定响应也覆盖真实普通双方对话→咨询→单台体验线索→后续本人稳定表达，只有最后一步长期化；没有助手评价自动长期化。

外部状态核验在第一阶段前/后、视图选择后、第二阶段后与commit前执行。删除/纠正发生于任一调用或视图读取期间，当前结果stale，清工作区，停止下一阶段或拒绝最终结果。供应商错误与删除同时发生也执行清理，账本保留该供应商失败；已发送内容无法追回。root重绑定拒绝；其他用户存储变化不污染当前用户。

确认继续绑定实际相邻、已可用的问题；confirm恢复原推荐，unclear保持原待办，cancel不恢复；混合已知本人态度的短人物答复不得改派。范围确认后的修订可重启读取，原exclude历史仍保留。以上都是固定客户端程序证据，不证明DeepSeek理解正确或ISS-039已解决。
